# Major Ports Static Reference

`major-ports.geojson` is a small static reference layer for the Sealanes live map.

The coordinates and terminal categories are manually curated public-reference points for major container ports, oil/product terminals, LNG export terminals, and dry-bulk export ports. This file is not a live port-call dataset, not an official port boundary dataset, and not a complete global port gazetteer.

Port colors intentionally use the same high-level groups as vessel colors:

- `tanker`
- `lng_carrier`
- `container`
- `dry_bulk`
- `cargo`

The layer is contextual only. It should not be used for port congestion, terminal operations, cargo confirmation, or route execution decisions.
