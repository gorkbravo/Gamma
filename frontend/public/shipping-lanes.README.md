# Shipping Lanes Dataset

`shipping-lanes.geojson` is copied from the public `newzealandpaul/Shipping-Lanes` dataset:

- Source: https://github.com/newzealandpaul/Shipping-Lanes
- File: `data/Shipping_Lanes_v1.geojson`
- Citation requested by source: Benden, P. (2022). Global Shipping Lanes [Data set]. Zenodo. https://doi.org/10.5281/zenodo.6361763
- Source description: global shipping lanes/routes georeferenced from the CIA `Map of The Worlds Oceans, October 2012`, with later corrections by the dataset maintainer.
- License stated by source repository: Creative Commons Attribution-ShareAlike 4.0 International, with the repository's stated Statista exclusion.

Gamma uses this file as a static contextual map layer only. It is not used for routing, execution, vessel safety, or operational navigation.
