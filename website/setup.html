Running in about five minutes.

Start in mock mode. It runs the entire application, all thirteen surfaces, against bundled sample providers with no broker, no keys and no network. Once you have seen the shape of it, swap providers on one at a time.

Start here Get your API keys Repository

Mock mode, end to end

Three terminals: one for the backend, one for the frontend, and the one you started in. Nothing here contacts a broker or a paid provider.

Clone and create the environment

Gamma installs as an editable package with its dev extras, which brings in pytest and the desktop build tooling.

PowerShell
git clone https://github.com/gorkbravo/Gamma.git
cd Gamma
python -m venv .venv
.\.venv\Scripts\activate
pip install -e .[dev]
copy .env.example .env

Start the backend

MOCK_DATA=true selects sample providers for every domain. GAMMA_SESSION_TOKEN is a shared secret between the API and the frontend. The API rejects any request without it, so pick anything random and use the same value in both places.

PowerShell · terminal 1
$env:MOCK_DATA="true"
$env:GAMMA_SESSION_TOKEN="dev-only-random-token"
.\.venv\Scripts\python.exe -m uvicorn src.api.main:app `
  --host 127.0.0.1 --port 8000 --reload

Check it answered: http://127.0.0.1:8000/health is the one route that needs no token.

Start the frontend

The Vite dev server reads the API base and session token from the environment at start-up. The token must match the backend exactly.

PowerShell · terminal 2
cd frontend
npm install
$env:VITE_API_BASE="http://127.0.0.1:8000"
$env:VITE_GAMMA_SESSION_TOKEN="dev-only-random-token"
npm run dev -- --host 127.0.0.1 --port 5173

Open http://127.0.0.1:5173. You should land on the connection screen with a Mock badge, then pick Research View or Portfolio View.

Or run the desktop shell

Tauri is the primary desktop path. The Python launcher starts the backend and the shell together.

PowerShell
# Packaged desktop launcher
$env:MOCK_DATA="true"
.\.venv\Scripts\python.exe -m src.desktop_launcher

# Or Tauri in development
cd frontend
npm run tauri:dev

Going live, one provider at a time

Each switch is independent. Turn one on, confirm the tab reports the provider you expect, then move to the next.

Interactive Brokers

Start Trader Workstation, enable the API in its settings, and confirm the socket port. IB Gateway is not supported yet; the live path is TWS. Set MOCK_DATA=false and leave IB_MARKET_DATA_MODE=delayed unless you hold real-time subscriptions.

.env
MOCK_DATA=false
IB_HOST=127.0.0.1
IB_PORT=7497
IB_CLIENT_ID=1
IB_ACCOUNT=U1234567
IB_MARKET_DATA_MODE=delayed
BASE_CURRENCY=USD

Base currency matters more than it looks: changing it starts a new currency-specific portfolio-history trail and archives the previous one rather than deleting it.

Macro on live FRED

One key turns the entire Macro tab from cached to live. If an individual series fails, Gamma keeps the rest of the snapshot and returns a warning naming that series.

.env
FRED_API_KEY=your-fred-key
CENSUS_API_KEY=your-census-key  # optional: live US trade partners

Commodities on official data

eia gives you official US energy fundamentals. ibkr builds read-only futures curves from discovered contracts. That path needs a connected TWS session and futures market-data entitlements, and gets expensive in market-data lines, so keep the enabled universe tight.

.env
# Official US energy fundamentals
COMMODITIES_PROVIDER=eia
EIA_API_KEY=your-eia-key

# Or Gamma-constructed IBKR futures curves
COMMODITIES_PROVIDER=ibkr
IBKR_COMMODITIES_ENABLED=wti,henry_hub,gold,copper
IBKR_COMMODITIES_STARTUP_ENABLED=wti
IBKR_COMMODITIES_CONTRACT_DEPTH=12

Sealanes on live AIS

The key stays server-side. Gamma opens a short sampling window over your configured bounding boxes rather than holding an open firehose.

.env
MARITIME_PROVIDER=aisstream
AISSTREAM_API_KEY=your-aisstream-key
AISSTREAM_SAMPLE_SECONDS=6
# Optional JSON: [[[min_lat, min_lon], [max_lat, max_lon]]]
AISSTREAM_BOUNDING_BOXES=

Copilot

Leave the provider on mock for offline deterministic output, or point it at OpenAI. Fundamentals summaries and the Strategy Lab Script runtime reuse the same key with their own model settings.

.env
OPENAI_API_KEY=sk-your-key
GAMMA_COPILOT_PROVIDER=openai   # or: mock
GAMMA_COPILOT_REASONING_EFFORT=medium

Verify it

The backend suite forces mock listed-market providers before runtime import, so tests cannot accidentally reach Yahoo Finance or TWS.

Backend
.\.venv\Scripts\python.exe -m pytest
Frontend & desktop
cd frontend
npm run test
npm run build
npm run desktop:check
npm run backend:smoke
npm run desktop:smoke

Getting around

Gamma is keyboard-first. Tabs are reorderable in the sidebar, and the shortcuts follow your order, not a fixed one.

GAMMA

A read-only market research terminal. Built as a FastAPI backend, a Svelte frontend and a Tauri desktop shell. It runs on your machine, on your credentials, and it never places an order.
